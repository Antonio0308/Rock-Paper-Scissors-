# Rock Paper Scissors ✊ 📄 ✂️

A classic Rock-Paper-Scissors game built as part of the **Foundations** course in [The Odin Project](https://www.theodinproject.com/).

The main goal of this project is to practice programming logic and interactive interfaces.

## 🚀 Features

- **First to 5 points:** The first player to reach 5 wins takes the match.
- **Computer AI:** The computer makes a random choice (rock, paper, or scissors) every round.
- **Live Scoreboard:** Player and computer scores update in real-time.
- **Round & Game Feedback:** Text messages display the winner of each round and announce the final victor.

## 🛠️ Tech Stack

- **HTML / CSS** for structuring and styling the user interface.
- **JavaScript** for handling the game logic and dynamic interactions.
